# Eagle Eye — Modern Hybrid Homepage UI

A responsive, static homepage UI concept, ready for Claude Code or another developer to implement in a production stack.

## Preview
Open `index.html` in your browser. No build step is required.

## Files
- `index.html` — the complete responsive UI (HTML, CSS, minimal JS)
- `assets/eagle-mark.png` — adapted transparent-background mark from the supplied brand image
- `assets/retina.svg` — original illustrative retinal artwork (not a clinical retinal photograph)

## Developer handoff
Rebuild using React/Next.js or the desired framework and preserve the overall layout, component hierarchy, color tokens, and mobile breakpoints. Replace CSS-only device mockups and illustrative imagery with approved, authentic photos/renders of Eagle Lens. Wire the navigation, contact form/email, and any analytics or integrations to real endpoints.

## Things to verify before publication
1. The numeric glaucoma statistics are copied from the supplied website design and must be verified against primary sources. The third figure's context is intentionally marked unverified.
2. `hello@eagleeyetech.org` is a **placeholder email**, not a confirmed address. Replace with your real contact address.
3. All wording about capabilities is descriptive/aspirational. Validate all device, AI, and medical claims before publishing.
4. The prototype uses Google Fonts Manrope and falls back to system sans-serif when offline.

## Design tokens
- Primary purple: `#520090`
- Electric violet: `#8100d4`
- Ink: `#1d172b`
- Soft lavender: `#eee7f8`
- Light background: `#faf9fd`
- Typeface: Manrope, weights 400–800. No italic or script typefaces.
